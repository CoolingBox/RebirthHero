### 成长曲线（1~40 级，2026-10-15 v4.4：直接加算 + 速度占模）

模型见数值框架 §11。**标准轴**（用户定）：HP **1000**（+100/级）／ ATK **60**（+5/级）／ DEF **30**（**+2**/级；DEF 基准由 60→50→30 下调、**v4.3 起不乘定位系数**；**ATK 基准 v4.4 由 50 提到 60**）。

`Base   = 标准基准   × 定位系数 k × 基础随机 b × 速度占模 occ`　←（**DEF 无 k**）
`Growth = 标准每级增量 × 定位系数 k × 成长随机 g × 速度占模 occ`　←（每级增量，**直接加算**；**DEF 无 k**）
`属性(L) = Base + Growth × (L−1)`

- **成长是绝对值**：配置表直接写"每级加多少"（如血 +80.8/级、攻 +5.98/级、防 +1.56/级），**直接加算**，不再用百分比偏差
- **基础随机 `b`**：**±40%**（HP/ATK/DEF 三项共用）
- **成长随机 `g`**：**HP / ATK / DEF 各自独立**，取值 **[0.80, 1.20]（±20%）**——**三项均不为 0**（v3"某项完全不成长"已取消）
- **速度占模 `occ = clamp(1 − 0.6×(SPD−50)/50, 0.75, 1.25)`**：越快属性越低（石敢当 SPD40→×1.12，柳如烟 SPD60→×0.88）
- **曲线类型仍是先随机生成、再按形状反贴的标签**（判定规则见数值框架 §11），**不做满级收敛**

**关键性质**：三属性独立成长 → **侧重比 HP:ATK 会随等级漂移**，这是刻意换来的成长多样性（看 L1/L40 两端即可，中段呈线性）：

| 侠客 | HP/级 | ATK/级 | L1 HP | L40 HP | 手感 |
|---|---|---|---|---|---|
| 石敢当 | 152.3 | 5.15 | 1290 | **7230** | k 高（坦）+ 最慢 occ×1.12：全池最厚，但被贴"技巧"（b、g 双低） |
| 柳如烟 | 73.0 | 3.61 | 915 | **3762** | SPD60 占模 + g 双低：全池最薄 |
| 莫问剑 | 84.0 | 7.59 | 1413 | 4689 | k 高（输出 ×1.3）+ b 高：L1/L40 攻全池最高 |

分布 **5/5/6/4**（随机跑 10 个种子、取类型分布最均衡的一次 → **seed=7**）。**类型与"定位"（坦/输出/辅助/召唤）是两根独立的轴**——落在哪一类与战斗定位无关；且**标签相对标准轴判定、不含定位系数 k**，故 k 很高的石敢当（坦 ×1.6 血）虽被贴"技巧"，绝对血量仍是全池最高。

**v4.x 相对 v3 的改善**：
- **不再有"某项完全不成长"**：v3 里老乞丐/剑魔被随机判成"攻击完全不成长"、与定位直接冲突；v4 三项均非 0 + g 收窄到 ±20% → 该问题消除。
- **满级跨度收敛**：L40 ATK 从 5.5× 回落到 **2.2×**、L40 HP 从 3.7× 回落到 **1.9×**——"满级属性差不多、侧重不同"基本达成。
- **DEF / ATK 多轮调整（v4.1 → v4.4）**：DEF 基础 60→50→**30**、每级 0.6→**2**、**移除定位系数**，满级 **×3.66**；**ATK 基准 50→60**（标准单次伤害 110→**60**，HP:ATK 20:1→**16.7:1**），**内功 Kd 由用户定为 100**。**2026-10-16 换算折表 + 三只 Scale 归 1** → **表值即战斗值**：**全池 L1 DEF 4.7 ~ 10.6**（中心 7.22）、**L40 21.1 ~ 31.0**；DEF/级 0.39 ~ 0.63。**DEF 前中期存在感比 v4.x 明显**（@60 档 L1 减 **7.9%~17.7%**），后期（单次 255 档）反而薄到 8.3%~12.1%。
- **仍待观察**：b 的 ±40% 是否让个别定位模糊（如坦的 L1 HP 低于辅助）；若需更强约束，按定位收窄 b 区间（坦/输出 b∈[0.85,1.25]）。**当前按用户口径保持纯随机。**

## 二、资质系统（每世客栈刷新）

### 随机维度

| 维度 | 档位 | 概率 [PLACEHOLDER] |
|------|------|---------------------|
| 星级 | ★1 / ★2 / ★3 / ★4 / ★5 | 50% / 30% / 12% / 6% / 2% |
| 成长率 | 每维（HP/ATK/SPD）独立掷 −20% ~ +30% | 均匀分布 |
| 资质词条 | 0 个 / 1 个 / 2 个 | 40% / 45% / 15% |

- **星级**：**气血 / 攻击**的乘数（★1=×1.0，每星 +15%），**不含速度**——2026-10-16 口径"高星行动频率去掉"。rationale：DPS ≈ 攻击 × 频率，若 ★ 同时乘两者就是**二次放大（★5 ≈ ×2.6）**，不该让一个 2% 概率的乘数承担这种杠杆；速度的方差交给成长率的 `SpdPct`。星级仍是"这把的手气"的主要方差来源，5 星 2% 制造客栈刷屏时刻。
- **成长率**：三维独立掷，总和期望为正但单维可为负——"瘸腿天才"（如 ATK+30%/SPD−20%）比全+10% 更有构筑话题性。rationale：构建差异化来自缺陷，不来自全能。

### 与经济的咬合

客栈是**银两**的常驻 sink（GDD §4.2 的货币列已改名为银两）；手动刷新付费递增是"赌资质"的边际成本——刷得越多越贵，理性玩家会在第 3~4 次停手 [PLACEHOLDER · 验证路径：M2 playtest 观察玩家刷新次数分布，若普遍刷到 6+ 次说明递增曲线太缓]。

### M2.3 落地（2026-10-16）

**实现**：`Scripts/Game/Inn/` —— `Inn`（状态机：栏位/刷新/招募/编队）、`HeroQuality`（资质掷骰 + `ApplyTo` 套用）、`InnConfig`（参数，**已全进 `TuningConfig` 总账**）；内容表 **`QualityConfig`**（第 6 张，6 条词条）。`HeroBuilder` 新增可选资质参数，**在技能装配前应用**（"气血上限%"类技能要按新气血上限折算）。

**探针实测（10000 次）**：星级分布 49.6 / 30.1 / 12.3 / 5.9 / 2.1%（期望 50/30/12/6/2 ✓）；词条 0/1/2 个 = 41.3 / 43.7 / 15.0%（期望 40/45/15 ✓）；三维成长率均值 ≈ 4.9%（期望 5.0），**单维为负约 40%**（"瘸腿天才"的来源 ✓）。★5 + 满成长 + 双词条 → HP **2.29×** / ATK **2.39×** / SPD **1.30×**（SPD 只吃成长率，不吃星级）。

**界面**：`Scripts/Game/Battle/View/InnView.cs` —— 4 栏位卡（名字 / ★ / 星级乘数 / 三维成长率 / 词条 / 招募按钮）+ **已招侠客的编队开关**（点一下上阵/下阵，满员时禁止再加）；`BattlePanel` 左上角「客栈 ⌂」进入，**打开即暂停战斗**（含结算等待），点「返回战斗」恢复原状态。⚠️ 仅编译通过，**待实机验收**。

**词条八类已全部实装（2026-10-16）**：`MulPct` / `HealPct` / `SummonHpPct` / `DmgTakenPct` 四个原"待实装"效果全部接上（见 GDD 决策 31）。
