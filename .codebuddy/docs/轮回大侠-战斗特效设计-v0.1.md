## 0. 现状：有信息，没有动作

| 已有 | 说明 |
|---|---|
| 飘字 `FloatLayer` | 伤害 / 治疗 / 护盾 / 掉落，0.7s 上浮淡出 |
| 卡头横幅 | 武学名（含 `×N` 重放段数），1.2s |
| 血条拖尾 | 两段式（0.12s 变色停留 + 0.32s 滑到新值） |
| 音效 | `hit_light` / `hit_heavy` / `death` / `spawn` |

**缺的是"打击感"**：现在一次攻击 = 目标血条掉一截 + 冒一个数字。
玩家看不出这是外功硬劈、内功震伤、毒发、还是盾被弹开——四者在屏幕上长得一模一样。

## 1. 三条设计原则

**① 形状必须先于颜色。**
挂机游戏玩家是扫视的。同一时刻可能有 3 张卡在挨打，颜色来不及分辨，
所以每种伤害用**不同的几何形状**：外功是"线"、内功是"环"、真伤是"裂"、毒是"泡"、火是"焰"。

**② 特效不许进信息带。**
卡底 84px 是血条 / 名字 / 行动条。所有特效锚定在**卡面上 2/3**（人物区域），
斩击线可以越出卡框（我们已经做了破框），但**不能覆盖信息带**。

**③ 总量硬上限。**
8 张卡 × 10Hz 刷帧，最坏情况一帧内 6 次命中。特效池上限 64 条，
超出丢最旧的——宁可少看一个火花，也不能掉帧。

## 2. 视觉语法（形状语言表）

| 语言 | 用在 | 形状 | 动势 |
|---|---|---|---|
| **线** | 外功（刀/剑/拳） | 一条斜向亮线 + 外层半透明宽线 | 从攻击者向目标"扫"过去，0.16s 内长到全长 |
| **环** | 内功（掌/音/震） | 2~3 圈同心圆，由目标向外扩散 | 0→46px，越外越淡 |
| **裂** | 真伤 | 竖直撕裂线 + 紫色余晖 | 先闪一帧全白，再裂缝张开 |
| **泡** | 毒 | 3 个小圆，从卡底向上升 | 0.8s 匀速上浮，左右轻微摆 |
| **焰** | 火 | 4 个三角形，贴卡底抖动 | 0.5s，幅度 3px，频率 12Hz |
| **芒** | 治疗 | 3 个菱形光点，自下而上 | 0.6s，绿色，末尾收拢到卡顶 |
| **罩** | 护盾 | 卡面外一圈六边形描边 | 0.35s，两次呼吸（0.5→1.0→0.7 透明度） |
| **符** | 召唤 | 地面椭圆双环，反向旋转 | 0.5s，缩放到 0.2 后消失 |
| **影** | 闪避 | 卡面副本向右上偏移 8px | 0.25s 淡出，alpha 0.25 |
| **碎** | 死亡 | 8 条碎片线向外 + 卡片下沉 6px | 0.45s，仅首领级用满 |

## 3. 事件 → 特效映射（核心表）

`Anchor` = 用 `HeroCardLayer.TryGetAnchor` 取卡面上部锚点；`T` = 时长（秒）

### 3.1 普攻与受击

| 事件 | 特效 | 几何 / 参数 | T |
|---|---|---|---|
| 普攻命中（外功） | **斩线** | 攻击者锚点→目标锚点；内层 2px 亮白、外层 7px 该阵营色 alpha 0.35；倾角跟随方向 | 0.16 |
| 命中点火花 | **4 条短射线** | 长度 10~14px 随机，从命中点向外，白色 alpha 0.9→0 | 0.12 |
| 目标抖动 | **卡面位移** | 沿攻击方向位移 2px，回弹 1px（`sin` 衰减两拍） | 0.08 |
| 内功命中 | **扩散环** | 目标锚点；3 圈，r 6→46，青白色 alpha 0.7→0 | 0.28 |
| 真伤命中 | **裂线 + 白闪** | 竖线 40px 从中心张开；目标卡 `modulate` 白闪 1 帧（alpha 0.25 叠加） | 0.20 |
| 闪避 | **残影 + 飘字** | 卡面副本右上 8px；飘字「闪」斜体灰白 | 0.25 |
| 被护盾吸收 | **罩闪** | 护盾六边形亮度脉冲一次（不重画整圈） | 0.15 |

> **分级**：单次伤害 ≥ 目标最大生命 12% 时，斩线加长 30%、火花 +2 条；
> ≥ 25% 时追加一次 40ms 的**屏幕轻微抖**（±2px，仅此一档，不要叠）。

### 3.2 死亡

| 事件 | 特效 | 说明 |
|---|---|---|
| 杂兵 / 侠客死亡 | 卡面灰度 + 下沉 6px + 8 条碎片 0.45s | 灰度用 `modulate` 到 0.55 亮度，**不做全灰**——要认得出是谁 |
| 首领死亡 | 追加：全屏 0.12s 白闪 + 碎片 ×2 + 缓慢下落 | 一场只发生一次，值得"贵" |

### 3.3 武学（按效果族）

| 效果族 | 特效 | 备注 |
|---|---|---|
| 单体伤害 | 斩线按 `DmgKind` 选"线/环/裂" | 与普攻同一套语言，只是更长、更亮（×1.4） |
| 群体伤害 | 以**每个目标**为圆心各放一次环/线 | 目标数 3 时总量 ×3，注意预算 |
| 治疗（Heal/HoT） | **芒**（3 菱形）从卡底浮到卡顶 | HoT 每跳只放 **1 个**菱形（不是 3 个），否则每秒都在爆 |
| 护盾 | 目标卡外**罩**（六边形描边），由内向外扩 4px | 护盾被打掉时叫一声"叮"（音效），不放特效 |
| 召唤 | 目标格位**符**（双环反向转） | 只有"出现"这一下，不要持续 |
| 毒（叠层） | **泡** 3 个 + 卡面淡绿一帧 | 每跳伤害放 1 个泡（跟 HoT 同规则） |
| 火（灼烧） | **焰** 贴卡底 | 持续期间常驻（这条是唯一的"持续特效"，用最低亮度） |
| 破绽 | 卡面 **2 道折线裂纹**（暗红） | 持续到破绽清零；层数 ≥2 时再加一道 |
| 沉默 | 卡头挂灰色「封」印章，0.9s | 与卡头横幅**并列**显示，不抢位置 |
| 斩杀（MissingHp） | 目标脚下**血色上升箭头** + 目标生命条闪红 | 这类是"处决"，要给仪式感 |
| 引爆（PoisonBurst） | 目标卡**绿爆环** + 全屏绿闪 8% | 全屏闪一局最多 1 次/2s，防频闪 |
| 按盾加伤（ShieldScale） | 施法者卡面**金色盾形**射向目标 | 让"我有盾所以打得痛"这件事看得见 |
| 自损（SelfHpLoss） | 施法者卡面**红纹**扫过 + 自己的掉血飘字（已有） | 强调"这是我付的代价" |
| 反伤（Reflect） | 从受击者向攻击者**反向斩线**（暗红） | 方向必须反过来，否则玩家以为是自己打的 |
| 闪避类武学触发 | 同「受击·闪避」 | — |

### 3.4 屏幕级（P2，先不做）

清层闪光 / 大劫开场字 / 首领登场横幅 / 连杀数字。这些属于"节奏"，不属于"打击感"，分开做。

## 4. 为什么是这些时长

| 值 | 依据 |
|---|---|
| 斩线 0.16s | 短于一次行动周期（最快 SPD 62 ≈ 1.6s/次），连击时能连成"刀风"，又不会糊成一片 |
| 环 0.28s | 内功要"有余韵"，比线慢一档——这是外功/内功在节奏上的区别，不只是形状 |
| 飘字 0.7s（已有） | 特效必须**短于飘字**，否则数字还没读完特效就盖上去 |
| 死亡 0.45s | 长于任何攻击特效，让"倒地"成为这一拍的终点 |
| 连击错峰 40ms | 多段/重放时逐段延迟，形成"连斩"；不延迟会看起来像一次 |

## 5. 工程方案

### 5.1 为什么是"一个自绘层"，不是粒子/素材

- 项目**没有任何粒子或素材资源**（全部是 ColorRect + Label + 现有立绘）
- 8 张卡同屏，粒子系统（`CPUParticles2D`）每卡一套会带来几十个节点的开合开销
- 程序化绘制能**按伤害类型动态调色与几何**——同一套代码画出线/环/裂/泡，素材做不到

**结论**：新增 `Scripts/Game/UI/BattleFxLayer.cs`（`Control` 子类，单个 `_Draw`）。
所有特效都是 `List<FxItem>` 里的一条记录（kind / from / to / t / dur / color / power），
每帧 `QueueRedraw()` 一次全画掉；`FxItem` 超过 64 条时丢最旧的。

```
BattleManager（逻辑）──语义调用──▶ BattlePanel.PlayFx(kind, from, to, color, power)
                                        │
                                        ▼
                                 BattleFxLayer._Draw()  ← 单一 CanvasItem
```

### 5.2 需要的"补洞"

> 2026-11-14 更新：前两行**已实装**。落地做法与本文的最初设想不同 —— DoT 没走 `RaiseDamage`
> 复用，而是单开了 `OnDot(src, tgt, amt, burn)`：DoT 没有"出手方向"，混进 `OnDamage` 会被
> `KindOf` 判成外功并画出一条斩线，等于告诉玩家"有人打了他一下"。

| 缺什么 | 现状 | 补法 | 状态 |
|---|---|---|---|
| **闪避没有事件** | `DealDamage` 判到闪避直接 `return 0`，只 `St.Dodges++` | `OnDodge(att, tgt, skill)` + 引擎在 `St.Dodges++` 处抛 | ✅ 已实装 |
| **DoT 不冒飘字** | `DotDamage` **一条事件都不抛**（毒/火每跳完全静默） | `OnDot(src, tgt, amt, burn)`；只报**真正扣到气血**的部分 | ✅ 已实装 |
| **伤害类型拿不到** | `OnDamage` 只带 `skill` 名 | 表现层按名字在 `attacker.Skills` 里查 `DmgKind`（缓存），不改引擎 | ✅ 已实装（P0） |

⚠️ **加事件必须同时改 `BattleReplay` 三处**（`ReplayKind` 枚举 / 录制 / 派发）：
漏任何一处，播片时该事件会被**静默丢弃**（不会有报错，画面只是少了一样东西）。

### 5.3 预算

| 项 | 上限 |
|---|---|
| 同时存活特效 | 64 条（超了丢最旧） |
| 一帧最多新增 | 12 条（群攻 4 目标 ×3 语言） |
| 全屏闪 | 1 次 / 2s |
| 屏幕抖 | 只在大伤害（≥25% 最大生命）时，±2px / 40ms |
| 每帧绘制调用 | `draw_line` × ≤120、`draw_arc` × ≤40、`draw_polygon` × ≤30 |

## 7. 怎么判断"做坏了"（验收信号）

| 坏掉的样子 | 判据 |
|---|---|
| 特效糊成一片 | 3 张卡同时挨打时，看不出谁在打谁 → 斩线方向必须清晰 |
| 掉帧 | 战斗帧率 < 55fps（8 卡 + 群攻）→ 减粒子/减圈数 |
| 数字读不出 | 飘字被特效盖住 → 特效必须画在飘字**下面**（层级：卡 < 特效 < 飘字 < 横幅） |
| 信息带被污染 | 血条区域出现任何特效 → 锚点算错 |
| 疲劳 | 连续挂机 5 分钟后"看到特效就烦" → 降低常驻特效（火/破绽）亮度，或提供"特效减淡"设置 |
