### 逐个人的设计理由

**苏合香（医毒双修）**
现有的奶都是纯奶：血量越低越有价值，但**队伍里一旦不需要奶，她就成了一个空位**。
她给治疗轴加了第二条腿——受击时往攻击者身上叠毒，奶不住的局转成毒伤局。
数值上 HP 800 / ATK 52 落在"苏小药与花想容之间"，不抢她们的极端值；SPD 52 略微快于纯奶（她还要抢叠毒窗口）。

**裴听风（盲眼听风）**
闪避这条线一直是散的：扫地僧血最少、女飞贼靠速度，**没有一个"站着挨打也不死"的前排**。
他 HP 1080 / DEF 7.4 是标准前排，靠"每 4 次受击完全闪避 + 闪后反击"吃多段敌人。
⚠️ 注意 2026-11-13 的引擎修复：闪避现在**也计入受击次数**，所以他是"每 N 次闪一次"而不是无敌——
这正是他能存在的前提（修之前这种角色是物理免疫，会毁掉整个关卡曲线）。

**秦铁衣（炉火锻兵）**
全队增益目前只有阵圣（阵法）一个人扛。铁匠走的是**开战即生效的常驻增益**（52 剑气纵横：全队攻击 +12%，整场），
自己低攻高血。这让"1 号位顶谁"产生新答案——以前顶铁震山是为了活，现在顶他还能让后排多打 12%。
数值刻意把 ATK 压到 46（比铁震山 66 更低），避免"又能 buff 又能打"。

**顾青弦（七弦凝霜）**
现有群攻少、内功群攻更少，而内功恰恰是"克高防"的唯一手段（比例化解，对小伤害更友好）。
琴师用 239 三叠浪（内功、敌方全体）做主输出，用 174 迟脉掌点控减速 18%：
减速让全队多打一轮，是**隐形的时间收益**，比再加一点倍率有意思。
HP 860 / DEF 6.2 是后排的常规脆度，靠位置而不是靠属性活。

**雷万钧（一刀断水）**
破绽卡池只有 3 张（197/227/237），且全是 T1 小卡——**机制在，但没有一个角色能把它撑成流派**。
他用 2 力劈华山（4.2× 外功，**代价是不能普攻**）+ 237 破竹斩挂破绽：
"不出普攻"本身就是大刀的形象，而破绽让这一刀的收益随队友段数放大。
HP 1150 保证他能站前排把这个循环跑起来。

**温三娘（醉拳自损）**
`自损气血上限` 这类卡只有两张（13 七伤拳、41 天地同寿），一直没人敢用——它反直觉：**用血条换伤害**。
醉拳是唯一能把它讲通的形象：13 七伤拳打 3.84× 真伤、自损 5%；40 困兽犹斗在血量掉到 50% 以下时再 +50% 攻击。
于是"越喝越猛、越猛越残"变成一条可计算的曲线，而不是靠面板。

## 4. 落地顺序建议

1. **先加 2 个**（苏合香 + 雷万钧）——她们补的机制最独立，改动面最小
2. 跑探针确认流派带没被拉宽，再批量加剩下 4 个
3. 敌方卡最后加（新层段会立刻改变推图曲线，需要单独的曲线验证）
