# 《轮回大侠》境界表与道行天赋树 v0.1

> 依据：GDD §4.2（五乘区）+ 数值框架（乘区间乘算、道行亚线性）。
> 境界乘区 = 此生纵向大跳；天赋树 = 道行唯一出口，永久生效。

## 一、境界表（境界乘区）

| 境界 | 乘区值 | 突破条件 [PLACEHOLDER] | 解锁项 |
|------|--------|------------------------|--------|
| 炼气 | ×1 | —（开局） | 武学槽×2 |
| 筑基 | ×10 | 修为 5 千 + 通关第 15 层 | 武学槽×3 |
| 金丹 | ×100 | 修为 8 万 + 通关第 35 层 | 客栈栏位+1 |
| 元婴 | ×1,000 | 修为 120 万 + 通关第 60 层 | 装备栏位+1 |
| 化神 | ×10,000 | 修为 2 千万 + 通关第 90 层 | 召唤物上限+1 |
| 合体 | ×100,000 | 修为 3 亿 + 通关第 125 层 | 客栈免费刷新+1 |
| 大乘 | ×1,000,000 | 修为 50 亿 + 通关第 165 层 | 武学槽+1（指定侠客） |
| 渡劫 | ×10,000,000 | 修为 8 百亿 + 通关第 210 层 | 大劫预告提前量+50% |

**设计说明**：
- 乘数每境 ×10——rationale：滚雪球的"跳档"必须大到玩家能感知数量级变化，×2、×3 的乘区在增量游戏里等于没有。10 倍一跳配合敌方 a=1.16/层，每境大约对应 40~50 层的推进空间（1.16^50 ≈ 1650 ≈ 10^3.2），表中层数门槛按此排布，略紧于纯乘数推导 [待验证：M3 节奏调参]。
- 解锁项与乘数并重——每境给"一个数量级 + 一个新玩法格子"，突破按钮点击感翻倍。
- 修为费用增长（5千→8百亿，约 ×15/境）刻意快于产出增长，缺口由转世后的根骨/图鉴乘区补——**这就是"不转世推不动"的数学来源** [待验证：M3 模拟无转世玩家卡死在金丹~元婴之间]。

### 福缘支（经济与收集，10 节点）

| # | 节点 | 效果 [PLACEHOLDER] |
|---|------|---------------------|
| 1 | 小富 | 修为产出+10% |
| 2 | 拾荒 | 武学掉落率+10% |
| 3 | 小富Ⅱ | 修为产出+15% |
| 4 | 鉴宝 | 商店轮换栏位+1 |
| 5 | 解锁侠客：阵圣 | 侠客池+1 |
| 6 | 积德 | 道行获取+10% |
| 7 | 拾荒Ⅱ | 高稀有武学权重+15% |
| 8 | 讲价 | 客栈招募费−15% |
| 9 | 图鉴大师 | 图鉴乘区效果 ×2 |
| 10 | 财神附体 | 修为产出+25% |

**设计说明**：
- 三分支对应三种转世后的"这世我要怎么打"：根骨=硬推（数值碾压），悟性=构筑（格子与机制），福缘=快滚（经济效率）。每世开局看客栈资质再决定点哪支——局外 build 与局内 build 联动。
- 每支第 8 或第 4/5 节点埋侠客解锁，数值玩家也会被引去看树的中段。
- 第 10 节点是"乘区乘区"（放大该支全部投入），防止深点贬值。
- 反"点哪条都行"检查（GDD §6 验收）：三支的最优解随当世资质分布变化——如果 M3 playtest 出现"无脑根骨"，先砍混元（根骨10）再说话。
